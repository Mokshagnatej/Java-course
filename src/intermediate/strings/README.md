# 🧵 Strings & Text Processing in Java

> **Intermediate Module 04** — String manipulation, memory management, and mutability.

## 🎯 Key Concepts to be Covered
- **String Pool (`String Constant Pool`)**: Heap vs Pool, string interning.
- **Immutability**: Why Strings are immutable in Java and security/threading implications.
- **String Methods**: `length()`, `charAt()`, `substring()`, `indexOf()`, `split()`, `trim()`, `equals()` vs `==`.
- **`StringBuilder` vs `StringBuffer`**: Mutable sequences, performance in loops, thread-safety differences.
- **Regular Expressions (`Regex`)**: Pattern matching and validation.
