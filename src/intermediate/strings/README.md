## 🎯 Key Concepts & Curriculum Roadmap

- **String Pool (`String Constant Pool`)**: Heap vs Pool mechanics, string interning (`intern()`).
- **Immutability Architecture**: Why Strings are immutable in Java, security implications, and multi-thread safety.
- **Essential String API**: `length()`, `charAt()`, `substring()`, `indexOf()`, `split()`, `trim()`, `equalsIgnoreCase()`.
- **Content vs Identity**: `equals()` vs `==` in-depth memory comparison.
- **`StringBuilder` vs `StringBuffer`**: Mutable sequences, memory allocation in loops, and thread-safety differences.
- **Regular Expressions (`Regex`)**: Pattern matching, token validation, and string replacements.
