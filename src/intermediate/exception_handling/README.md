# 🛡️ Exception Handling & Robust Systems

> **Intermediate Module 05** — Handling runtime errors, writing resilient programs, and debugging.

## 🎯 Key Concepts to be Covered
- **Throwable Hierarchy**: `Error` vs `Exception`, Checked vs Unchecked exceptions.
- **Try-Catch-Finally**: Handling multiple exceptions, resource cleanup.
- **Try-with-Resources**: Automatic resource management (`AutoCloseable`).
- **`throw` vs `throws`**: Propagating exceptions through method call stacks.
- **Custom Exceptions**: Creating domain-specific exception classes.
