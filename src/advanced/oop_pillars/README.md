# 🏛️ The Four Pillars of OOP

> **Advanced Module 02** — Mastering Encapsulation, Inheritance, Polymorphism, and Abstraction.

## 🎯 Key Concepts to be Covered
- **Encapsulation**: Private fields, getters/setters, data hiding.
- **Inheritance**: `extends` keyword, `super`, method overriding (`@Override`).
- **Polymorphism**: Compile-time (method overloading) vs Runtime (dynamic method dispatch).
- **Abstraction**: `abstract` classes vs `interface`, default & static methods.
- **SOLID Principles**: Foundation of clean, maintainable object-oriented architecture.
