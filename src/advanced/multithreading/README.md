## 🎯 Key Concepts & Curriculum Roadmap

- **Thread Creation Mechanisms**: Extending `Thread` vs implementing `Runnable` vs `Callable<V>` with return futures.
- **Thread Lifecycle States**: `NEW`, `RUNNABLE`, `BLOCKED`, `WAITING`, `TIMED_WAITING`, and `TERMINATED`.
- **Race Conditions & Critical Sections**: Protecting shared mutable state with `synchronized` methods and blocks.
- **Deadlock, Livelock & Starvation**: Deadlock detection, ordering locks, and prevention patterns.
- **Inter-Thread Communication**: Monitor methods (`wait()`, `notify()`, `notifyAll()`) and producer-consumer queue design.
- **Modern Concurrency (`java.util.concurrent`)**: `ExecutorService`, `ThreadPoolExecutor`, `CompletableFuture`, `AtomicInteger`, `ReentrantLock`, and concurrent collections.
