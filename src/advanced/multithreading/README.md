# ⚡ Multithreading & Concurrency

> **Advanced Module 06** — Asynchronous execution, thread lifecycle, and thread synchronization.

## 🎯 Key Concepts to be Covered
- **Thread Creation**: Extending `Thread` vs implementing `Runnable` vs `Callable<V>`.
- **Thread Lifecycle**: NEW, RUNNABLE, BLOCKED, WAITING, TIMED_WAITING, TERMINATED.
- **Synchronization**: `synchronized` methods & blocks, race conditions, deadlocks.
- **Inter-thread Communication**: `wait()`, `notify()`, `notifyAll()`.
- **Modern Concurrency (`java.util.concurrent`)**: `ExecutorService`, `ThreadPoolExecutor`, `Future`, `CompletableFuture`, `AtomicInteger`, `ReentrantLock`.
