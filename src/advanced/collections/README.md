# 📚 Java Collections Framework (JCF)

> **Advanced Module 03** — High-performance data structures and algorithm containers.

## 🎯 Key Concepts to be Covered
- **Core Interfaces**: `Iterable`, `Collection`, `List`, `Set`, `Queue`, `Deque`, `Map`.
- **Implementations**:
  - `ArrayList` vs `LinkedList`
  - `HashSet`, `LinkedHashSet`, `TreeSet`
  - `HashMap`, `LinkedHashMap`, `TreeMap`
  - `PriorityQueue`, `ArrayDeque`
- **Iterators & Streams**: `Iterator`, `ListIterator`, `for-each`, and basic Stream operations.
- **Comparators**: `Comparable<T>` vs `Comparator<T>`.
