## 🎯 Key Concepts & Curriculum Roadmap

- **Core Interfaces**: `Iterable`, `Collection`, `List`, `Set`, `Queue`, `Deque`, `Map`.
- **List Implementations**: `ArrayList` (dynamic array) vs `LinkedList` (doubly-linked nodes) performance tradeoffs.
- **Set Implementations**: `HashSet` (O(1) hashing), `LinkedHashSet` (insertion order), `TreeSet` (Red-Black tree O(log n)).
- **Map Implementations**: `HashMap` (buckets, collisions, resizing), `LinkedHashMap`, `TreeMap` (sorted keys).
- **Queue & Deque**: `PriorityQueue` (binary heap min/max), `ArrayDeque` (double-ended queue/stack).
- **Iterators & Streams**: Fail-fast `Iterator`, `ListIterator`, and declarative Stream API pipelines.
- **Sorting & Comparison**: `Comparable<T>` natural ordering vs `Comparator<T>` custom lambda strategies.
