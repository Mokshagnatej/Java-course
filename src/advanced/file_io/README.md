# 💾 Java File I/O & Serialization

> **Advanced Module 05** — Reading, writing, streaming data, and Java NIO.2.

## 🎯 Key Concepts to be Covered
- **Classic I/O (`java.io`)**: Byte streams (`FileInputStream`, `FileOutputStream`) vs Character streams (`FileReader`, `BufferedReader`, `PrintWriter`).
- **Modern NIO.2 (`java.nio.file`)**: `Path`, `Paths`, `Files` utilities (`Files.readAllLines`, `Files.write`).
- **Object Serialization**: `Serializable` interface, `transient` keyword, `ObjectInputStream` / `ObjectOutputStream`.
- **Handling CSV & JSON**: Structured data parsing patterns.
