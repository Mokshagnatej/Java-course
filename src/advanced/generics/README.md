# 🧬 Java Generics & Type Safety

> **Advanced Module 04** — Compile-time type safety, generic classes, methods, and wildcards.

## 🎯 Key Concepts to be Covered
- **Generic Classes & Interfaces**: Defining `class Box<T>`, `interface Repository<T, ID>`.
- **Generic Methods**: Type inference and generic method syntax `<T> void print(T item)`.
- **Bounded Type Parameters**: Upper bounds (`<T extends Number>`).
- **Wildcards**: Unbounded (`?`), upper bounded (`? extends T`), lower bounded (`? super T`), PECS principle.
- **Type Erasure**: How generics work at runtime in the JVM.
